# ClickHouse Data Loader (ETL Script)

Скрипт на Python для загрузки данных из файлов `.csv` и `.xlsx` в базу данных ClickHouse. 
Реализует логику историчности данных (SCD Type 2) и автоматическое создание таблиц.

## Основные возможности
- Чтение файлов CSV и Excel.
- Автоматическое создание таблицы в ClickHouse при первом запуске.
- Динамическая генерация DDL-схемы с использованием библиотеки `sqlglot`.
- Поддержка двух режимов загрузки:
  - `incremental`: добавление новых строк.
  - `full`: деактуализация старых строк (установка `actual_end`) и вставка новых.
- Безопасная работа с существующими таблицами: если в таблице нет служебных колонок, скрипт не ломает её, а выводит ошибку и прекращает работу.
- Логирование всех этапов работы.
- Встроенный генератор тестовых данных для быстрого старта.

## Установка и запуск
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`
3. Создайте файл `.env` на основе `.env.example` и укажите ваши доступы к ClickHouse.
4. Сгенерируйте тестовые данные (опционально): `python generate_test_data.py`
5. Запустите скрипт: `python main.py`

Для тестирования скрипта положите файл с данными в папку `data/` или укажите путь к нему при запуске. Сами данные в репозитории не хранятся по соображениям безопасности и размера (папка `data/` и расширения файлов добавлены в `.gitignore`).

## Структура проекта
- `main.py` — основной скрипт.
- `generate_test_data.py` — скрипт для генерации тестового Excel-файла.
- `.env.example` — пример файла с переменными окружения.
- `.gitignore` — правила исключения файлов для Git.
- `requirements.txt` — зависимости.
- `data/` — локальная папка для файлов с данными (не отслеживается Git).

## Технические детали
В скрипте реализована логика добавления системных колонок `actual_begin` и `actual_end` для отслеживания актуальности данных (SCD Type 2). 
*Примечание: для больших объемов данных в ClickHouse рекомендуется использовать движок `ReplacingMergeTree` вместо оператора `ALTER UPDATE` для повышения производительности.*
